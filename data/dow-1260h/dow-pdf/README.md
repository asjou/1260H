# The Department of Defense (aka War) PDFs, saved by hand

Defense.gov blocks scripts, so nothing here downloads these. Open each PDF in your browser, save it
into this folder, and name it by the date on the PDF's web address, for example:

    2026-06-08.pdf    https://media.defense.gov/2026/Jun/08/...SECTION-1260H.PDF

`python3 run.py replay` and `python3 run.py decide` list every PDF saved here next to each
difference, so you can open the right one and search it for the name. The scripts never read
these files: the PDF is for the person deciding.
