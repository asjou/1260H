How this page was made

  1. A scheduled script asks the Federal Register for new notices about this list.
  2. Each notice is saved, with its SHA-256, before anything reads it.
  3. Fixed rules (no AI) turn the saved text into rows, each with its page.
  4. One AI step exists, only for a notice the rules cannot read; code checks its answer.
  5. An editor checks every change against the source links and approves it.
  6. This page is rebuilt from the approved data.
